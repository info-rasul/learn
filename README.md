# Грамматика Мёрфи по методу «Полиглот»

Веб-тренажёр английской грамматики: 145 уроков по разделам *English Grammar in Use* (Raymond Murphy, 5th ed.),
тренировка — как в «Полиглоте»: перевод русских фраз на английский со сборкой ответа по словам.
Теория и фразы написаны заново, текст книги не используется. React + Vite, статический сайт для GitHub Pages.

## Возможности

- Вход по почте (без пароля и подтверждения) — почта разделяет данные учеников на одном устройстве.
- 145 уроков в 16 разделах книги: теория + практика (сборка фразы из слов или ввод с клавиатуры), озвучка ответов.
- Подсветка ошибок: лишние и пропущенные слова.
- DeepSeek: разбор конкретной ошибки и анализ всей истории со списком слабых тем.
- Интерактивная таблица глагола, статистика, экспорт истории.

Сервера и базы данных нет: история, прогресс и настройки хранятся в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Контент

Уроки лежат в `public/data/lessons/NNN.json`, список файлов — в `public/data/index.json`.

```json
{
  "id": 1,
  "section": "Настоящее и прошедшее время",
  "title": "Present continuous (I am doing)",
  "subtitle": "Что происходит сейчас",
  "theory": [
    { "type": "p", "text": "Абзац, можно <b>жирный</b>" },
    { "type": "h", "text": "Подзаголовок" },
    { "type": "list", "items": ["пункт 1", "пункт 2"] },
    { "type": "table", "head": ["A", "B"], "rows": [["1", "2"]] },
    { "type": "tip", "text": "Подсказка" }
  ],
  "items": [
    { "ru": "Я люблю.", "en": ["I love."] },
    { "ru": "Он не врач.", "en": ["He isn't a doctor.", "He is not a doctor."] }
  ]
}
```

Первый вариант в `en` — эталон (из него строятся плашки), остальные — допустимые альтернативы. Регистр, знаки препинания и сокращения (`don't` = `do not`, `'d` = `had`/`would`, `'s` = `is`/`has`) при проверке не учитываются.

Проверка уроков: `node scripts/validate-lessons.mjs [первый последний]`.

## DeepSeek

Ключ вводится в приложении: **Настройки → DeepSeek**. Он хранится только в браузере пользователя и уходит напрямую в `https://api.deepseek.com`.
Модель по умолчанию — `deepseek-flash` (`deepseek-v4-flash` — устаревший псевдоним, тоже работает).

Для локальной разработки можно задать значения по умолчанию в `.env` (см. `.env.example`).
Не задавайте `VITE_DEEPSEEK_API_KEY` при сборке для GitHub Pages — он попадёт в публичный JS-бандл.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` при каждом пуше в `main` собирает проект на последней версии Node.js
и кладёт `dist/` в ветку `gh-pages`, из которой GitHub Pages публикует сайт: https://info-rasul.github.io/learn/

Маршрутизация через `#` (HashRouter), поэтому прямые ссылки и обновление страницы работают без настройки сервера.
